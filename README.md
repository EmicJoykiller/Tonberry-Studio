# Tonberry Studio website

A lightweight static website for Tonberry Studio, a Toronto-based 3D printing studio serving customers across Canada.

## Preview locally

Open `index.html` in a browser. Keep the `assets` folder alongside the HTML, CSS, and JavaScript files.

## Deploy with GitHub and Vercel

1. Create a GitHub repository and add the contents of this folder at the repository root. Include `index.html`, the CSS and JavaScript files, and the complete `assets` folder.
2. In Vercel, import that GitHub repository.
3. Use the repository root as the project root and choose the Other preset. No install or build command is needed for this static site.
4. Deploy.

No `vercel.json`, package manager, or build step is required.

## Before sharing the live URL

- Add the YouTube link when that channel is ready; the Instagram profile and enquiry email are configured on the site.
- Set the social preview image to an absolute live URL once the Vercel domain is assigned.
- Add a contact form later if you want visitors to send longer project briefs directly from the site.
- Replace the concept renders with additional finished-product photos as the portfolio grows.

## Assets

The `assets` folder contains six portfolio photos, four MP4 clips, the cat logo, full logo artwork, Instagram QR code, and supporting illustration SVGs. The unused MOV clip is not included.
